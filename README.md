# 📊 분야별·신규사업별 예산 분석 인포그래픽 대시보드

사용자가 제공한 엑셀(.xlsx, .xls) 또는 CSV 파일을 업로드하면 **분야별 투자 점유율** 및 **2027년 신규(신설·착수) 사업**을 인터랙티브 인포그래픽과 차트로 즉각 시각화하는 바닐라 자바스크립트 기반 웹 애플리케이션입니다.

---

## 🚀 빠른 시작 방법 (Zero-Build)

별도의 Node.js 설치나 빌드 과정 없이, 브라우저에서 바로 열어 사용할 수 있습니다.

1. **대시보드 열기**:
   - `c:\work1022\web\index.html` 파일을 더블 클릭하거나 브라우저(Chrome, Edge 등)로 엽니다.
2. **기본 데이터 확인**:
   - 첫 실행 시 `2027년 국방예산 정부안 중점투자사업` 32개 사업 데이터가 기본 탑재되어 즉시 인포그래픽을 확인할 수 있습니다.
3. **파일 업로드 테스트**:
   - 상단 드래그 앤 드롭 영역에 `c:\work1022\web\sample_upload.xlsx` 또는 `c:\work1022\web\sample_upload.csv` 파일을 끌어놓아 동적 갱신을 테스트할 수 있습니다.

## 🎯 주요 기능

### 1. 엑셀/CSV 업로드 & 헤더 자동 인식 (Fuzzy Mapping)
- 사용자가 업로드한 파일의 컬럼명이 기본 명칭과 약간 다르더라도 정규식을 통해 자동 인식합니다:
  - `연번`, `분야 (중점영역)`, `세부 사업 / 주요 지표`, `구분/단위`, `2026년 (A)`, `2027년 정부안 (B)`, `증감 (B-A)`, `증가율 (%)`, `핵심 내용 및 보도자료 박스 원문 근거`

### 2. 신규 사업(순증/신설) 자동 감지 엔진
- 전년도(2026년) 예산이 `0`원이거나, 증가율에 `순증/신규`, 사업명/원문에 `신규·신설·착수`가 포함된 경우 자동으로 `[NEW]` 뱃지가 부여되고 신규 사업 전용 갤러리 및 차트에 반영됩니다.

### 3. 동적 인포그래픽 & 시각화
- **상단 핵심 KPI 카드 4종**: 총 예산 규모, 전년대비 순증액, 2027 신설 사업 개수 및 총 배정액, 최대 증액/급증 사업 스포트라이트.
- **분야별 예산 비중 도넛 차트**: 각 중점영역별 파이 점유율 (조각 클릭 시 해당 분야로 대시보드 자동 필터링).
- **분야별 전년대비 비교 막대 차트**: 2026 vs 2027 예산 증감 대비.
- **신규 사업 TOP 랭킹 차트**: 신설 사업 중 예산 규모 상위 프로젝트 수평 막대.
- **신규 사업 하이라이트 카드 덱**: 신규 사업들의 명칭, 배정액, 핵심 추진 내용을 시각적인 카드로 진열.

### 4. 인터랙티브 탐색기 & 세부 모달
- 사업명, 분야, 원문 내용 실시간 통합 검색.
- 분야별 셀렉터, 단위별 셀렉터, **'신규 사업만 보기' 원클릭 토글**.
- 테이블 뷰 ↔ 카드 그리드 뷰 자유 전환.
- 행 또는 카드 클릭 시 **세부 사업 상세 모달 팝업**(전년대비 게이지 바, 보도자료 박스 원문 근거 전문) 표출.

### 5. 유틸리티 및 목록 엑셀 저장
- **전체 사업 데이터 목록 엑셀 다운로드 (.xlsx)**:
  - 현재 화면(검색어, 분야 필터, 신규사업 토글 등이 적용된 상태)에 나타난 사업 데이터 목록을 원클릭으로 정식 엑셀 파일로 저장합니다.
  - 가독성 최적화 열 너비, 숫자 포맷, **Excel 자동 필터(AutoFilter)**가 기본 적용되어 파일 열람 시 즉시 엑셀 필터를 사용할 수 있습니다.
- **CSV 다운로드**: 한글 깨짐 방지를 위해 **UTF-8 BOM**이 적용된 표준 CSV 파일 저장 지원.
- **필터별 동적 파일명 부여**:
  - 신규사업 필터 시: `2027신규신설사업목록_YYYYMMDD.xlsx`
  - 특정 분야 필터 시: `사업목록_[분야명]_YYYYMMDD.xlsx`
  - 검색어 입력 시: `사업목록_검색결과_YYYYMMDD.xlsx`
- **양식 다운로드**: 사용자가 양식에 맞춰 입력할 수 있는 표준 엑셀 템플릿 다운로드.
- **인쇄 / PDF**: 보고용으로 최적화된 A4 프린트 스타일 지원.
